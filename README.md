# Support 25qi's tools

Donation page shared by all of 25qi's free tools: https://25qi.github.io/support/

Each tool links here with `?from=<tool>` (for example `?from=watchnotes`) so the page can thank people for that tool. Payment itself happens on ECPay; this page never handles payment details.

To turn donations on, put the ECPay payment URL into `ecpayUrl` and/or the Buy Me a Coffee page URL into `bmcUrl` in `config.js`. To add a tool, add an entry under `tools` in the same file.
